Roadmap

Where Tangent is headed next.

Soft persistence shipped in v1. Upcoming work hardens that layer, then opens the same margin-note flow beyond Claude.

  1. Shipped

    v1 — Claude margin notes

    Highlight on claude.ai, ask in a side bubble, soft-persist threads per conversation. Live on the Chrome Web Store.

  2. Next

    Persistence patches

    Coming updates focus on re-anchoring reliability, clearer restore behavior after long absences, and edge cases when Claude’s DOM or message layout shifts. No product surface change—more durable bubbles.

  3. Later

    v2 — Claude + ChatGPT

    Generalize Tangent so the same gutter experience works on both claude.ai and ChatGPT, with a shared interaction model and host-specific adapters under the hood.
