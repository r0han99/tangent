Roadmap

Where Offthread is headed next.

v1 shipped as Tangent on Claude. v2 is Offthread: the same gutter on Claude, ChatGPT, and Gemini, with host adapters under the hood.

  1. Shipped

    v2 — Offthread on Claude, ChatGPT, Gemini

    Rebrand, purple/white site, and host adapters for claude.ai, ChatGPT, and Gemini. Same Chrome Web Store listing (item id unchanged).

  2. Next

    Host API hardening

    ChatGPT and Gemini web endpoints change often. Upcoming patches re-verify stream shapes, improve re-anchoring when those DOMs shift, and tighten persistence namespaces.

  3. Later

    More hosts

    Additional AI chat surfaces behind the same adapter interface, if demand shows up in Issues.
